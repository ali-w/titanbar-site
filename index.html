Titanbar

Titanbar is a small personal Android app. It opens a single text box from a hardware key and runs one-line commands: search your apps, message or call a contact, set a timer, alarm or calendar reminder, save a note, and add items to your own Google Tasks lists.

The only Google data it touches is your own Google Tasks, using the Google Tasks API, so that - buy milk adds a task to a list named "To-do" and . eggs adds one to a list named "Shopping". Nothing else is read from your Google account.
